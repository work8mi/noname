# 宿主模式：将魂轮回作为 noname 的模式运行

## 背景与决策

将魂轮回需要复用 noname 的战斗引擎（事件系统、卡牌结算、技能实现、AI），而其肉鸽元层（地图、商店、技能槽、融合进化）需要自定义流程与 UI。我们决定把将魂轮回实现为 noname 的一个新模式（必要时附加扩展），源码自包含在 `general-soul-samsara/`，构建输出到 `apps/core/mode` 与 `apps/core/extension`，且只依赖 `noname` 的公开导出。

## 备选方案

- **引擎嵌入**：独立应用，自建启动流程与 UI。流程最自由，但需要改造与配置/标准流程耦合的 `boot`，原型期成本高。
- **复制引擎**：将引擎核心复制进新项目、与上游脱钩。自由度最高，维护成本最高。

## 后果

- 原型期以 noname 为宿主，独立发行前需要一次剥离/嵌入改造；元层代码必须保持自包含，不直接依赖 `apps/core` 内部实现。
