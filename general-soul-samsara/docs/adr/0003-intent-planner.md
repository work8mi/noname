# 敌人意图由独立规划器产出，出牌交还引擎 AI

noname 引擎的 AI 是反应式的，不产出"下回合计划"，把它的即时决策展示为意图会失真（显示"防御"实际用了攻击牌），也无法表达蓄力、召唤、封印等抽象动作。决定：每个敌人持有**意图表**，每回合选定并展示下一个动作（攻击 / 蓄力 / 判定 / 召唤 / 防御 / 封印 / 弃牌），由意图驱动其回合行为；**具体出牌与响应（闪、无懈、目标选择）仍由引擎 AI 处理**；普通怪用词缀参数化意图表，精英/Boss 用阶段脚本改写意图表。

## 备选方案

- 直接显示 AI 决策结果：实现最省，但意图不可靠，玩家无法据此做留闪 / 拆牌 / 卖血决策。
- 每个敌人手写完整行为脚本：完全可控，但维护量随敌人数量爆炸，且浪费引擎现成的牌局 AI。

## 后果

- 意图是敌人配置的一等数据，新增敌人 = 意图表 + 词缀/阶段配置。
- 意图与实际行为的一致性需要测试覆盖；隐藏/假意图是展示层规则，不改规划器本身。
