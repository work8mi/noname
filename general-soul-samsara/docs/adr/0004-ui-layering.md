# 战斗 UI 复用引擎，元层 UI 用 Vue 3

引擎的战斗 UI（手牌、结算动画、目标选择、装备区）是多年打磨的资产，重做不现实；而地图、商店、技能槽、奖励三选一这些元层界面在引擎里不存在。决定：**战斗层直接复用引擎 UI 与元素系统**；**元层用 Vue 3 组件**实现（宿主仓库已内置 `vue.esm-browser` 与 import map 中的 `vue`），以全屏覆盖层的形式与战斗层切换；两层只通过一个薄状态层（RunState + 事件）通信。

## 备选方案

- 元层也用 `ui` / `lib.element` 手写 DOM：单一技术栈，但列表、网格、拖拽等面板交互的开发速度显著更慢。
- 战斗层也自绘：成本不可行，且要重写全部结算动画与目标选择。
