## 1. 定位与技术形态

**[决策]** 将魂轮回是运行在 noname 引擎之上的新模式（宿主模式）：战斗层完全复用引擎（事件系统、卡牌结算、标包技能实现、AI、战斗 UI），肉鸽元层（地图、商店、技能槽、奖励、事件）为新代码。项目源码自包含于 `general-soul-samsara/`，只依赖 `noname` 的公开导出，为将来独立发行保留剥离路径（ADR-0001）。

## 4. 战斗规则

### 4.1 阶段结构

**[继承 + 提案]** 沿用引擎完整阶段：准备、判定、摸牌、出牌、弃牌、结束。概要设计 §3.1 只列了"开始/判定/摸牌/出牌/弃牌"，但【观星】等技能按原版触发于准备阶段、大量技能触发于结束阶段，因此必须保留引擎的完整阶段（对概要设计的补全）。

### 4.2 手牌、抽牌与体力

- **[继承]** 初始手牌 4 张；每回合摸 3 张；手牌上限 = 当前体力；抽牌堆抽空时洗弃牌堆；两堆皆空时不抽牌、不疲劳。
- **[决策 Q7]** 体力跨战斗保留，不回满；回复来源为休整节点、事件、【桃】/回复类牌与局外强化（局外本阶段不存在）。
- **[继承]** 战斗结束时：弃牌堆、装备区与除外区的牌全部回到卡组；下一战重新洗牌、重新发 4 张初始手牌；体力与卡组构筑变化（升级、删牌）跨战斗保留。

### 4.3 出牌与技能

- **[继承]** 无行动点；默认每回合使用【杀】限 1 次；【酒】每回合限 1 次；锦囊、装备按原版。
- **[决策 Q8]** "原版描述"统一以 `apps/core/character/standard` 标包的实现与文本为基准，技能 id 沿用（`wusheng`、`longdan`、`paoxiao`…）；精英/Boss 技能同样取自标包。个别例外需单列并说明原因。
- **[继承]** 不削弱、不额外加限次；多刀通过【咆哮】【诸葛连弩】、宝物与事件获得。

### 4.4 除外

- **[决策 Q6]** 术语统一为**除外**：卡牌使用后移出本场战斗、不进入弃牌堆；战斗结束后回到卡组。与肉鸽惯例的"消耗（永久移出）"明确区分，术语表见 `CONTEXT.md`。
- **[提案]** 需要跨战斗永久减少卡组的手段只有：商店删牌、事件转化、诅咒净化；不使用"永久消耗"机制。

### 4.5 座次、距离与攻击范围

- **[决策 Q17]** 按原版规则实现：玩家固定 0 号位，敌人按固定顺序占 1..N 位，召唤物追加到末尾，死亡后重排；1v1 时距离自然退化为 1。武器攻击范围、±1 马保有原版语义。
- **[提案]** 战斗 UI 在敌人头像处显示与玩家的距离；当【杀】/【顺手牵羊】等因距离不可选时，给出明确提示。

### 4.6 敌人意图

- **[决策 Q11]** 每个敌人每回合从自己的意图表中选择一个动作（攻击 / 蓄力 / 判定 / 召唤 / 防御 / 封印 / 弃牌），意图在玩家回合开始前可见并驱动其回合行为；具体出牌、响应（闪、无懈、目标选择）仍由引擎 AI 处理。普通怪意图全可见；精英/Boss 可隐藏部分或显示假意图（M0.3）。
- **[提案]** 意图数据是敌人配置的一部分，词缀与 Boss 阶段通过改写意图表生效。

### 4.7 敌人手牌

- **[决策 Q24]** 敌人持有隐藏手牌，来源为按敌人配置的牌表（抽完按规则重洗）。玩家不可见其数量与内容，但【过河拆桥】【顺手牵羊】【火攻】等直接作用于其手牌，原版语义完整保留。
- **[提案]** 敌人每回合摸牌数：小怪 2、精英/Boss 3；弃牌阶段按引擎默认（弃至体力值）。

### 4.8 判定牌来源

- **[提案]** 判定牌从**被判定者自己的牌堆顶**翻出（玩家判定用玩家卡组，敌人判定用敌人牌表）；判定后的牌进入其弃牌堆。这样【观星】【鬼才】等操控牌堆顶的技能与原版语义一致。

### 4.9 1v1 黑名单

- **[决策 Q9]** 维护"1v1 黑名单"：无法按原版执行的技能/牌不入掉落池、商店与敌人技能表；能按原版执行但对玩家不利的（如【桃园结义】连带治疗敌人、【五谷丰登】让敌人摸牌）保留。
- **[提案]** 初始名单：技能 `lijian`（离间）、`hujia`（护驾）、`jijiang`（激将）、`jiuyuan`（救援）、`huangtian`（黄天）与所有主公技；卡牌【借刀杀人】。名单实现为一份数据文件，可随内容扩充维护。

### 4.10 多敌人与召唤

- **[决策 Q15]** 原型支持 1vN；Boss 的召唤阶段生成真实的小怪（独立玩家座位、独立牌表与意图），而非"单体等效机制"。
- **[提案]** 召唤上限：同时存在的召唤物 ≤ 2；召唤物不计入章节奖励，死亡不重复触发额外奖励。

## 5. 武将与技能

### 5.1 武将

- **[决策 Q3]** 原型仅开放赵云（4 血，专属技能【龙胆】`longdan`）；无选将界面，直接以其开局。
- **[继承]** 专属技能不占通用槽、不可拆卸、可升级与进化（§4.2）。后续武将按概要设计 §4.1/§4.3 模板扩展。

### 5.2 通用技能与槽位

- **[继承]** 6 个通用槽：3 主动 + 3 被动；满槽后只能替换、融合或进化；宝物可 +1 槽（主动或被动各最多 +1）。
- **[继承]** 品质：普通 / 稀有 / 传奇；前期多掉普通、精英掉稀有、Boss 掉传奇。
- **[继承]** 掉落智能：70% 匹配已有标签，30% 跨流派随机；战后三选一。
- **[已接入]** 品质权重：普通战第 1 章 7:3:0.5、第 2 章 4:5:1（普通:稀有:传奇）；精英 1:6:3；首领 0.2:2:8。当前技能池为 6 普通 / 4 稀有（观星、奇袭、反馈、遗计）/ 2 传奇（铁骑、鬼才）；品质池耗尽时自动回退到其他品质。

### 5.3 技能等级

- **[决策 Q19]** 技能 Lv1→Lv3；升级给小幅、可预期的强化（数值 +1、条件放宽、限次 +1），**Lv2 为进化配方门槛**；进化后等级继承。
- **[已接入]** 升级入口为休整节点「升级技能」；Lv2 作为进化门槛。数值效果已接入 5 个可由引擎事件干净实现的技能：咆哮、奸雄、空城、遗计、反馈（见技能元数据表）；其余技能的 Lv2/Lv3 暂只作进化门槛，数值效果待后续接入。

### 5.4 融合与进化

- **[决策 Q12]** 均为**配方制**：手工维护映射（融合 `A + B → C`，进化 `A → B`），原型内置 5-8 条；融合产物占 1 个通用槽；不实现"任意同标签技能自动融合"。

**[提案] 原型配方（6 条融合）**：

| 配方 | 产物 | 核心机制 |
| --- | --- | --- |
| 武圣 + 铁骑 | 神威 | 红牌当杀；杀指定后判定，红则不可闪且伤害 +1 |
| 苦肉 + 奸雄 | 狂骨 | 失去体力摸 2；受伤获得伤害牌 |
| 苦肉 + 反馈 | 死士 | 失去体力摸牌；受伤获得来源一张牌 |
| 观星 + 鬼才 | 天命鬼才 | 观星后可改判；判定成功后摸 1 |
| 制衡 + 奇袭 | 奇策 | 弃 X 摸 X；黑牌当过河拆桥 |
| 制衡 + 遗计 | 谋略 | 弃 X 摸 X；受伤摸 2 |

**[提案] 原型进化路线（示例，每技能 2 条按概要设计 §5.4 逐步补齐）**：武圣 → 青龙 / 义绝；咆哮 → 燕人咆哮 / 虎啸；苦肉 → 诈降 / 搏命；观星 → 天命 / 星落；龙胆（专属）→ 龙魂。

> 已接入：6 条融合 + 6 条进化。融合产物用 `group` 聚合两个原版技能的机制（原版描述不变）；进化保留原技能并追加一条自定义触发。执行入口为休整节点「融合 / 进化」，进化需输入技能 Lv2；产物占用原槽位、进化继承等级。苦肉进化命名为「苦肉·诈降」以避免与融合产物重名（融合「苦肉 + 反馈」产物为「死士」）。专属技能（龙胆）的进化待专属技能系统接入后实现。

### 5.5 原型技能清单

- **[决策 Q3] M0.1（6 个）**：主动 = 武圣 `wusheng`、苦肉 `kurou`、制衡 `zhiheng`；被动 = 咆哮 `paoxiao`、奸雄 `jianxiong`、空城 `kongcheng`。
- **[提案] M0.3（12 个）**：在 M0.1 基础上增加 观星 `guanxing`、铁骑 `tieqi`、奇袭 `qixi`、反馈 `fankui`、鬼才 `guicai`、遗计 `yiji`。全部取自标包，标签覆盖 杀/闪/爆发/卖血/多刀/过牌/判定/控制/防御 九类。

## 6. 卡组与卡牌

### 6.1 初始卡组

**[继承]** 赵云 20 张：杀 7、闪 7、桃 3、酒 1、无中生有 1、过河拆桥 1（概要设计 §6.1 微调表）。

### 6.2 卡牌池分层

- **[决策 Q14] M0.1**：杀、闪、桃、酒、无中生有、过河拆桥、顺手牵羊（初始模板涉及的牌）+ 小怪牌表所需牌。
- **[决策 Q14] M0.2**：加入决斗、南蛮入侵、万箭齐发与武器/防具。
- **[决策 Q14] M0.3**：加入特殊锦囊（桃园结义、五谷丰登、火攻、铁索连环；借刀杀人按 §4.9 排除）、诅咒牌、卡牌升级版。
- **[决策 Q14]** 坐骑与宝物类装备卡最后接入。
- **[已接入]** 商店卡池已含基本牌、基础锦囊、特殊锦囊（桃园结义 / 五谷丰登 / 火攻 / 铁索连环，借刀杀人按 §4.9 排除）与武器 / 防具，每次上架 5 张；诅咒牌通过事件获取，卡牌升级以升级标记实现。坐骑与宝物类装备卡仍留到原型后接入。

### 6.3 卡牌升级

**[继承]** 杀+ 伤害 +1；闪+ 闪避后摸 1；桃+ 回复 2；无中+ 摸 3；拆+ 拆 2 张；顺+ 偷 2 张。升级为永久（跨战斗）且每张牌独立。

> 已接入六种升级；拆+ / 顺+ 的额外一张为随机取得（精确指定目标牌的交互待后续版本）。升级入口：休整节点（免费，每次一张）与商店升级服务（75 金币）。

### 6.4 删牌与转化

**[继承]** 商店删牌直接移除；事件转化（如 3 张杀 → 1 张万箭齐发）；休整升级一张牌；宝物提供全局转化效果。

## 7. 金币与商店

### 7.1 金币来源

**[已调整]** 普通战 20-30；精英 50-70；Boss 100-140；事件 20-80；售卖卡牌：基本牌 15 / 其他牌 30，每章 3 次。**战斗不再掉落卡牌**：卡牌只来自商店购买与事件奖励/转化，因此金币是构筑的主要资源（概要设计 §11.6 的"卡牌"奖励项已被本规格移除）。

### 7.2 商店内容

- **[决策 Q21]** 仅固定项：5 张卡牌、2 个技能、1 个宝物、删牌服务、刷新服务。
- **[决策 Q21]** 卡牌升级在休整节点；融合/进化通过战后奖励与事件获得；商店不提供融合/进化/升级服务。

### 7.3 价格

**[继承]** 普通卡 50；稀有卡 80-120；传奇卡 150-200；主动技能 100-150；被动技能 120-180；宝物 150-300；删牌 75（每次 +25）；刷新 25。价格与金币产出是首要平衡旋钮。

## 8. 地图与事件

### 8.1 结构与层数

- **[决策 Q13]** 手工骨架 + 有限随机：每章固定拓扑骨架（保证章尾挑战、商店、休整可达），节点类型按配额随机填充；种子化随机生成留到 M0.3 之后。
- **[决策 Q22]** 原型每章 **7 层**（6-8 层区间的初值），两章合计 14 层，单局 20-30 分钟；正式版再评估扩到 10-12 层。

### 8.2 节点配额与骨架

**[提案] 每章骨架（7 层）**：

| 层 | 节点 |
| --- | --- |
| L1 | 战斗（固定入口） |
| L2 | 战斗 ×2 |
| L3 | 战斗 / 事件 / 商店 |
| L4 | 战斗 ×3 |
| L5 | 商店 / 战斗 ×2 |
| L6 | 休整 / 事件 |
| L7 | 章尾挑战（第 1 章华雄，第 2 章张角） |

- **[决策 Q20]** 第 1 章以精英华雄收尾，第 2 章以多阶段张角收尾；Boss 前固定休整（L6 提供）。
