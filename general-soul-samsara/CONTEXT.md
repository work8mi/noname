# 将魂轮回

基于 noname 引擎的单人 PVE 卡牌构筑肉鸽：用《三国杀》式的牌与技能做战斗，用《杀戮尖塔》式的分支地图、事件与商店做构筑。本文件只收录本项目特有的术语口径，不放实现细节；术语变更时同步更新需求规格。

## Language

### 单局与流程

**单局**（Run）：
从开局（选定武将）到死亡或击败最终 Boss 为止的一次完整游戏，目标时长 20-30 分钟。
_Avoid_: 一局、一跑、一把

**章节**：
单局的阶段划分。原型为 2 章，每章 7 层。
_Avoid_: 关卡、幕、大关

**层**：
章节内地图上的一排节点，玩家每层只能进入一个节点。
_Avoid_: 排、行、列

**节点**：
地图上的一个可进入点，类型为战斗 / 精英 / 事件 / 商店 / 休整 / 章尾挑战。
_Avoid_: 格、房间、关卡

**战斗**：
一次独立的引擎对局（1vN），牌组在每次战斗开始时重新洗牌，战斗结束后所有牌回到卡组。
_Avoid_: 对局、局（易与"单局"混淆）

**意图**：
敌人在玩家回合开始前预告的下回合动作（攻击 / 蓄力 / 判定 / 召唤 / 防御 / 封印 / 弃牌）。
_Avoid_: 技能预告、行动预告、预告

### 卡牌与牌堆

**卡组**：
玩家构筑并跨战斗携带的全部卡牌集合。
_Avoid_: 牌组、牌库、卡池（"卡池"指可获取内容的总体，不是玩家的集合）

**抽牌堆 / 弃牌堆 / 判定区 / 装备区**：
沿用引擎的牌堆术语，含义与原版一致。

**除外**（Exhaust）：
一张牌在本场战斗中使用后移出战斗、不进入弃牌堆；战斗结束后回到卡组重新可用。
_Avoid_: 消耗（肉鸽语境中通常指永久移出，本项目明确不用此含义）

**卡牌升级**：
对单张卡的永久强化（+），跨战斗保留。

**诅咒牌**：
负面卡牌，不能主动使用、占用手牌并参与抽牌循环。
_Avoid_: 诅咒卡（可接受，但统一写"诅咒牌"）

### 武将与技能

**专属技能**：
武将自带、不占通用槽、不可拆卸，可升级、进化、转形态的技能。
_Avoid_: 武将技、固有技、本命技

**通用技能**：
装入通用槽的技能，来自掉落、商店或事件，包括其他武将的专属技能（按原版描述装入）。
_Avoid_: 公共技、自由技

**通用槽**：
容纳通用技能的 6 个位置，固定 3 主动 + 3 被动；宝物可各 +1。

**技能等级**：
通用技能的 Lv1-Lv3 成长；Lv2 是进化配方的门槛。

**标签**：
技能与武将的流派标记（杀、闪、爆发、卖血、多刀、过牌、判定、控制、防御），驱动掉落倾向与配方。

**配方**（Recipe）：
手工维护的技能转化条目：融合 `A + B → C`，进化 `A → B`。
_Avoid_: 合成表、公式

**融合**：
两个技能按配方合成为一个高级技能，产物占 1 个通用槽。

**进化**：
单个技能按配方转为新形态，等级继承。

**1v1 黑名单**：
无法在 1vN 下按原版执行的技能与卡牌清单，不入任何掉落 / 商店 / 敌人配置。
_Avoid_: 禁用表、ban 表

### 元层与局外

**元层**：
战斗之外的界面与流程（地图、商店、事件、技能槽、奖励）。
_Avoid_: 外圈、外层

**局外**（Meta-progression）：
跨单局的解锁与成长进度。原型不包含。
_Avoid_: 元层（两者不同）

**质变宝物**：
改变规则层级的宝物，每局最多获取 1-2 个。

**词缀**（Affix）：
附加在敌人身上的肉鸽强化（铁甲、狂暴、护盾、召唤、吸牌、妖术…）。

**净化**（De-branding）：
公开分发前替换《三国杀》专有表达（名称、描述、美术、音频）的工作。
_Avoid_: 改名、去 IP 化

**调试面板**：
仅开发环境可见的调试工具，用于调平衡与测试铺设前置状态。
